# Concepts of Mathematics Coaching

A full-stack MERN application for Concepts of Mathematics Coaching, Hazaribagh, Jharkhand.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- Tailwind CSS
- GitHub Actions

## Project Structure

- `client` - Frontend application
- `server` - Backend API
- `docs` - Project documentation
- `.github/workflows` - CI/CD workflows

## Development

Frontend and backend will be developed independently and integrated through REST APIs.
